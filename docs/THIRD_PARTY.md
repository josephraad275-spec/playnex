# Third-party software and artwork

Original PlayNex source and geometric game artwork are MIT licensed (root LICENSE). Preserve copyright and license notices in redistributions. The game catalog's future entries are plans, not bundled third-party games.

The dependency lockfile records exact installed versions. Core dependencies use permissive licenses: React/React DOM (MIT), Vite (MIT), TypeScript (Apache-2.0), Tailwind CSS (MIT), ws (MIT), Lucide icons (ISC), Playwright (Apache-2.0). Include their distributed license files when packaging; reassess the full dependency tree and platform notices before native distribution. No external stock game artwork, copied branded card decks, paid fonts, advertising SDKs or tracking libraries have been added.
